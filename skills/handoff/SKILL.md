# handoff

세션이 남길 것을 기록한다. **git이 못 담는 것만** 담는다 —
미커밋 상태, 다음 슬라이스의 제약, 막힌 이유.

## 절차 (이 순서로, 산출물 4개)

1. `.harness/handoff/<YYYY-MM-DD-hhmm>.md` 생성 — 섹션 3개 고정:
   - `## 미커밋 상태` — `git status --porcelain` 결과와 그 이유
   - `## 다음 제약` — 활성 REQ·cwd·기준 HEAD, 다음 세션이 지킬 조건, 재사용할 검증의 소스 상태·근거 경로 (없으면 "없음")
   - `## 막힘` — 막힌 이유와 실패 종류. 실행 중·승인 대기·취소 중·결과 불명은
     명령·기존 handle 또는 요청 ID·마지막 관측·다음 확인 방법을 함께 기록한다. 없으면 "없음"
2. `.harness/handoff/LATEST.md` 를 새 파일과 같은 내용으로 덮어쓴다
3. 이 세션에서 확정된 결정이 있으면 `.harness/decisions.md` 에
   **한 줄씩** append: `- <YYYY-MM-DD>: <결정>` (여러 줄 서사 금지 — 동시 세션 병합 규약)
4. 진행 중 REQ가 있으면 해당 yaml의 상태·타임스탬프가 실제와 맞는지 확인하고 갱신한다

기록 전에 내용을 `lib/scrub.mjs`의 scrub에 통과시킨다 — detections가 있으면
치환된 텍스트로 저장하고 사용자에게 카테고리만 보고한다 (값 인용 금지).

## 금지

- 커밋된 변경 내역 요약 재기록 금지 — git log가 이미 담고 있다
- 미확정 브레인스토밍을 decisions.md에 넣지 않는다 — 결정만
- 관측을 멈췄다고 작업이 종료된 것으로 쓰지 않는다. 결과가 불명확한 명령을 재개 시 자동 재실행하지 않는다.
